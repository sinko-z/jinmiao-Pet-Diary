# 金喵宠物日记 🐾（微信小程序 · 暖阳主题）

一款面向**宠物爱好者**与**流浪动物救助者**的宠物记录微信小程序。按照《宠物记录微信小程序 · 产品需求文档》实现，全站采用**暖色系**视觉（奶油底 + 蜜桃橘 + 焦糖棕），并加入大量**小爪印**元素提升可爱度。

## ✨ 功能总览（需求模块 ↔ 页面映射）

## 🎨 暖色设计系统

定义于 `app.wxss`（CSS 变量 + 通用类）：

- 底色 `#FFFDF9 / #FFF7EE`（奶油）
- 主色 `#FF9F4A → #F47521`（蜜桃橘渐变，品牌按钮/强调）
- 强调 `#FF6B4A`（珊瑚，危险/走失）、`#7BA05B`（豆绿，救助/公园/认证）
- 文字 `#52311B / #6E4224 / #8C5A2B`（深→浅焦糖）、点缀 `#F2B04C`（暖金）
- 卡片白底 + 暖橙微阴影 + 蜜桃描边；页面头部大量使用暖橙渐变 + 爪印光斑

## 🚀 运行方式

1. 打开**微信开发者工具** → 导入项目 → 选择本目录；
2. AppID 可先用测试号或 `touristappid`（游客模式）；
3. 底部导航共 4 个 tab：**首页 · 社区 · 宠物店 · 我的**；
4. 演示流程建议：
   - 「我的」→ 微信登录 → 编辑资料；
   - 「宠物店」→ 我是商家，我要入驻 → 填资料上传营业执照/身份证 → **模拟审核通过** → 商家中心看数据；
   - 店铺详情可 **1-5 星打分评价**；
   - 宠物详情可查看/添加**好朋友**、书写**成长故事**、**邀请好友加入宠物家庭**；
   - 首页「附近宠物」查看定位附近可见的毛孩子。

> 说明：本项目为**完整可运行的前端演示**，数据来自 `utils/mock.js`，登录/审核为演示态；接入真实后端/云开发时替换数据源并打通 `wx.login` code2Session 与订阅消息即可，页面结构与数据结构保持不变。

## 🧩 已覆盖的非功能性需求（界面层）

- 微信登录态与会话管理：`app.js`（login / logout / updateUser / ensureLogin）
- 图片懒加载/压缩：`wx.chooseMedia` 压缩上传
- 定位：`getLocation / chooseLocation`（轨迹打卡、附近宠物、附近服务、走失），已在 `app.json` 声明权限
- 商家资质审核：营业执照 + 身份证照片收集与审核状态流转（demo 一键通过）
- 数据安全：联系方式等私密字段仅协作者/登录用户可见
- 兼容：基础库 2.10+ 通用 API，`style: v2`，适配安全区
